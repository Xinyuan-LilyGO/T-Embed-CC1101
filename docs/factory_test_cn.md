# Factory 工程测试说明

本文档基于 `examples/factory` 当前实现整理，用于 `T-Embed-CC1101` 工程样机、板级联调和出厂前功能验收。

## 1. 适用范围

- 适用硬件：`T-Embed-CC1101 V1.0`
- 不适用硬件：`T-Embed-CC1101 V1.1`
- 选装模块：`CC1101`、`PN532`、`nRF24`

启动页会根据 I2C 指纹识别硬件版本：

- `V1.0`：`0x24(PN532)`、`0x55(BQ27220)`、`0x6B(BQ25896)`
- `V1.1`：`0x22(XL9555)`、`0x55(BQ27220)`、`0x6A(SY6970)`

如果检测到 `V1.1`，程序会停留在启动页，不允许进入主菜单。

## 2. 测试准备

- 烧录 `factory` 固件
- USB 供电正常
- 建议同时打开串口，波特率 `115200`
- 必测辅料：
  - MicroSD 卡
  - 可观察的 WS2812 灯效环境
  - 可发声/录音的环境
- 按需准备：
  - 已知 WiFi 环境
  - ISO14443A 卡片/NFC 标签
  - 红外接收设备
  - CC1101 / nRF24 对端设备

## 3. 基本操作

- `ENC 旋转`：移动主菜单选择，或在子页面移动焦点到 `BACK`
- `BOOT`：进入页面 / 执行当前页面动作 / 焦点在 `BACK` 时返回
- `USER`：当前页面的辅助动作

主菜单固定操作：

- `ENC scroll`
- `BOOT open`
- `USER next`

## 4. 启动页检查

启动页会显示：

- 硬件版本
- 软件版本
- 固件生成时间
- Git 提交短哈希
- I2C 探测结果

通过标准：

- V1.0 板卡应显示 `V1.0 OK`，并允许按任意键或旋转编码器进入主菜单
- V1.1 板卡应显示阻止信息，不可进入主菜单
- 混合/未知指纹可以继续进入，但应记录为“需人工确认硬件配置”

## 5. 推荐测试顺序

建议按下面顺序测试，以便优先覆盖主板基础功能：

1. 启动页
2. `Battery / PMU`
3. `SD Card`
4. `TFT Display`
5. `WS2812 LEDs`
6. `MIC & Speaker`
7. `WiFi`
8. `IR TX / RX`
9. 选装模块：`CC1101`、`PN532 NFC`、`nRF24`
10. `Settings`

## 6. 页面测试说明

### 6.1 Battery / PMU

用途：

- 检查 `BQ27220` 电量计
- 检查 `BQ25896` 充电与 USB/VBUS 状态

操作：

- 进入页面后自动读取电池/PMU 信息
- `BOOT`：刷新一次状态
- `ENC` 旋转到 `BACK`，`BOOT` 返回
- `USER` 长按：执行关机

通过标准：

- 页面能稳定显示 `SOC`、电压、电流、VBUS/VSYS、充电状态
- 插入 USB 后，充电状态和总线状态应发生变化
- 未插 USB 时，长按 `USER` 可以关机
- 插 USB 时，长按 `USER` 应拒绝关机并提示先拔掉 USB

### 6.2 CC1101 Radio（选装）

说明：

- 页面进入前会先探测模块
- 如果模块未安装或 SPI 通信失败，主菜单会弹出提示，不进入子页面

操作：

- `USER`：切换频点 `315 / 433.92 / 868 MHz`
- `BOOT`：切换 `RX -> TX BURST -> SNIFF OOK`
- `ENC` 旋转到 `BACK`，`BOOT` 返回

通过标准：

- 已装模块时可以进入页面，且不出现 `Radio init failed`
- `TX/RX` 模式能与同参数对端正常收发
- `SNIFF OOK` 模式能检测到脉冲边沿/突发

备注：

- 该项需要匹配频点的对端设备与天线
- 若当前 BOM 未安装 CC1101，不计为失败

### 6.3 IR TX / RX

用途：

- 验证红外发送、接收、自发自收逻辑

操作：

- `USER`：切换预设码
- `BOOT`：
  - 默认焦点下：发送当前预设
  - 焦点在 `LOOP`：开/关自发自收模式
  - 焦点在 `BACK`：返回
- `ENC`：焦点在 `NONE -> LOOP -> BACK` 间切换

通过标准：

- `TX` 区发送计数递增
- `RX` 区能解析出协议、数值、位数和计数
- 开启 `LOOP` 后，页面能周期性自发自收
- `LOOP` 模式下，收发时 WS2812 亮紫灯，空闲时熄灭

### 6.4 MIC & Speaker

用途：

- 自动完成麦克风、喇叭、回环 3 个阶段的自检

阶段：

1. `MIC`：5 秒采样，靠近麦克风说话或制造声音
2. `SPK`：依次播放 `440 Hz / 1000 Hz / 880 Hz`
3. `LOOP`：8 秒麦克风到喇叭回放，讲话应听到延迟回放

操作：

- 页面进入后自动开始测试
- 测试完成后：
  - `USER`：重新测试
  - `BOOT`：重新测试
  - `ENC` 到 `BACK` 后 `BOOT` 返回

通过标准：

- `MIC` 阶段能检测到明显输入信号
- `SPK` 阶段能听到 3 个测试音
- `LOOP` 阶段讲话时能听到回放
- 最终结果显示 `PASS`

### 6.5 PN532 NFC（选装）

说明：

- 页面进入前会先探测模块
- 如果模块未安装或 I2C 无响应，主菜单会提示，不进入页面

操作：

- 将 ISO14443A 卡片/NFC 标签靠近天线
- 页面会显示 UID、卡类型、UID 长度、Card ID
- `BOOT`：重新初始化
- `ENC` 到 `BACK` 后 `BOOT` 返回

通过标准：

- 已装模块时可进入页面
- 页面能显示 `PN532 FW x.x`
- 标签靠近后能识别 UID
- 标签移开后能恢复等待状态

### 6.6 nRF24 Tx/Rx（选装）

说明：

- 页面进入前会先探测模块
- 如果模块未安装或 SPI 通信失败，主菜单会提示，不进入页面

操作：

- `USER`：切换预设信道
- `BOOT`：切换 `RX <-> TX`
- `ENC` 到 `BACK` 后 `BOOT` 返回

通过标准：

- 已装模块时可进入页面，且不出现 `Radio init failed`
- 与匹配参数的对端可正常收发
- `RX` 收到数据时计数递增，LED 有接收反馈

备注：

- 若 BOM 未安装 nRF24，不计为失败

### 6.7 SD Card

用途：

- 自动检查挂载、写入、读回、根目录访问

操作：

- 进入页面后自动执行测试
- `USER`：重测
- `BOOT`：重测
- `ENC` 到 `BACK` 后 `BOOT` 返回

通过标准：

- `Mount / Write / Read / Result` 四项均显示 `PASS`
- 能读取卡类型、容量/占用、根目录条目数
- 测试文件 `/t_embed_sd_test.txt` 创建、读回后删除成功

### 6.8 WiFi

用途：

- 扫描周围 AP
- 仅在发现指定 AP 时尝试连接

自动连接目标：

- `LilyGo-AABB`
- `xinyuandianzi`

如果两个都存在，优先连接 RSSI 更强的那个。

操作：

- 页面进入后自动扫描
- `BOOT`：
  - 默认焦点下：重新扫描
  - 焦点在 `BACK`：返回
- `ENC`：切换是否选中 `BACK`

通过标准：

- 页面能显示扫描结果前 3 项
- 发现目标 AP 时应进入连接，并显示 `JOINED`
- 连接成功后应显示 SSID、IP、RSSI，RSSI 和信号条会实时刷新
- 如果环境中没有目标 AP，应显示“仅扫描，不自动连接”，这属于正常结果

### 6.9 TFT Display

用途：

- 检查显示屏颜色、几何图形、文字显示和页面切换

内容：

- 概览页
- 纯色条
- 几何图形
- 文字显示

操作：

- 页面会自动轮播演示
- `BOOT`：
  - 默认焦点下：切换到下一个演示
  - 焦点在 `BACK`：返回

通过标准：

- 页面内容显示完整，无明显串屏/重影
- 纯色条颜色正确
- 几何线条和圆形显示正常
- 文本清晰可读

### 6.10 WS2812 LEDs

用途：

- 检查 8 颗 WS2812 的 RGB、白光、动态效果和亮度调节

图案：

- Solid Red
- Solid Green
- Solid Blue
- White
- Rainbow
- Chase Cyan

操作：

- 页面自动切换图案
- `USER`：切换亮度档位
- `BOOT`：
  - 默认焦点下：切换到下一个图案
  - 焦点在 `BACK`：返回

通过标准：

- 8 颗灯均能点亮
- RGB 三色和白光正常
- 动画连续，无卡死
- 亮度切换有效

### 6.11 Settings

用途：

- 辅助查看设备信息与运行状态
- 调整屏幕方向和自动休眠

项目：

- Device Info
- Rotation
- Sleep
- Auto Power
- Back

操作：

- `ENC`：切换项目
- `BOOT`：执行当前项目动作

通过标准：

- `Info` 可刷新芯片/频率/Flash/Heap 信息
- `Rotation` 可切换显示方向
- `Sleep` 可进入休眠，并可通过 `USER` 唤醒
- `Auto Power` 可切换自动休眠时间

## 7. 选装模块判定规则

以下页面默认按“选装模块”处理：

- `CC1101 Radio`
- `PN532 NFC`
- `nRF24 Tx/Rx`

判定规则：

- 如果当前板型 BOM 未安装该模块，主菜单出现“模块未找到/通信失败”提示，属于正常行为，不计为失败
- 如果 BOM 规定已安装该模块，但主菜单无法进入对应页面，则判定该模块装配或通信异常

## 8. 整机通过建议

基础板卡建议满足以下条件后，判定主板测试通过：

- 启动页硬件识别逻辑正确
- `Battery / PMU` 信息正常
- `SD Card` 自检通过
- `TFT Display` 显示正常
- `WS2812` 各颜色与亮度正常
- `MIC & Speaker` 最终显示 `PASS`
- `IR TX / RX` 至少完成一次可见收发验证
- `WiFi` 能稳定扫描；若测试环境提供目标 AP，则应完成连接
- 无死机、重启、花屏、持续串屏

如果项目 BOM 含选装模块，则还应补充：

- `CC1101` 收发正常
- `PN532` 读卡正常
- `nRF24` 收发正常

## 9. 串口辅助说明

多数页面在进入时会向串口输出帮助信息或状态信息，建议工程测试时保持串口打开：

- 串口：`115200`
- 便于定位：
  - RF 初始化失败
  - I2C/SPI 通信失败
  - SD 挂载/读写失败
  - WiFi 连接/超时重试
  - 音频自检阶段切换

## 10. 备注

- `factory` 更偏工程测试与板级联调，不是面向普通用户的最终 UI
- 若后续菜单项、按键逻辑、测试内容发生变化，应同步更新本文档
